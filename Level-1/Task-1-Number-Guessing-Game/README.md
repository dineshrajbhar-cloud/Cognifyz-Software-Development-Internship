# Number Guessing Game

### Cognifyz Software Development Internship
**Level 1 - Task 1**

## About
A simple Java console game where the user tries to guess a randomly generated number between 1 and 100.

The game gives "Too High" or "Too Low" hints and counts the number of attempts. It also allows the user to play again.

## Features
- Random number generation
- User input and validation
- High/Low hints
- Attempts counter
- Replay option

## Technologies
- Java
- Core Java
- Scanner
- Random

## How to Run
Open `NumberGuessingGame.java` in IntelliJ IDEA and run the `main()` method.
